# SAC23 Game Library v2.4.0

First public release of SAC23 Game Library: a Windows-local PS4 and PS5 collection viewer with cover-art cards, a single-click YouTube preview popup, multi-folder scanning, game/update/DLC grouping, offline cover reuse, favorites, Cover Inbox and reports.

**Install:** Extract the Windows release ZIP, install Python 3.10+ if needed, and double-click `Start_SAC23_Game_Library.bat`.

No game binaries, proprietary artwork, trailers, API keys or game installers are included. Online metadata availability varies; manual artwork selection is supported.
