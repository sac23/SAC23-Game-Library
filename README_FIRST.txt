SAC23 GAME LIBRARY v2.4.0 - WINDOWS
===================================
1. Install Python 3.10+ from https://www.python.org/downloads/windows/
2. Extract the entire ZIP to a folder on your PC.
3. Double-click Start_SAC23_Game_Library.bat.
4. In the browser, click Add games and select your game folders.
5. Choose Get covers and click a game to view its details and YouTube preview.

Original game files are scanned read-only and are never modified.
No game files or proprietary cover artwork are included in this package.

User data/cache is stored in %LOCALAPPDATA%\SAC23_Game_Library.
Optional metadata API keys are saved locally without encryption.
Read README.md for detailed help and privacy information.
